free-web-mcp — WebMCP demo

This page proxies the four MCP tools from free-web-mcp into the in-page AI via document.modelContext.registerTool(...). Open it in Chrome 149+ with the chrome://flags/#enable-webmcp-testing flag enabled and the AI in your DevTools console (or an attached WebMCP inspector) can call the tools directly.

Default points at the public ngrok demo. Set to your own Render URL or http://127.0.0.1:8000/mcp when running locally.
